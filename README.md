# Family Huddle

A cross-platform family task management app. Families organise chores, assign tasks to members, earn stars on completion, unlock badges and character progression, set goals, and chat.

## Tech Stack

- React 18 + TypeScript + Vite
- Supabase (PostgreSQL, Auth, Realtime, Storage)
- Capacitor 8 (Android)
- Tailwind CSS + shadcn/ui
- RevenueCat (subscriptions)
- Firebase Cloud Messaging (push notifications)

## Getting Started

```sh
npm install
npm run dev
```
